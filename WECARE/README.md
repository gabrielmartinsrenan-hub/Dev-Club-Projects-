We Care — Pet Care Landing Page

A friendly, modern landing page for a pet care service. Features a bold headline, a warm illustration, and a clear call-to-action to encourage visitors to explore services.

Mostrar Imagem

✨ Features
Navigation bar with Home, About, Product, Service, and Contact links, plus a highlighted "Login" button
Hero section with a bold "We Care" headline and supporting text about pet care
Illustration of a caregiver bonding with a pet, set against a soft circular background shape
Call-to-action button ("Explore") to guide users further into the site
Clean, minimal, and responsive layout
🛠️ Built With
HTML5
CSS3
JavaScript
