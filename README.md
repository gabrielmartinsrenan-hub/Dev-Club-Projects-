Easy Shopping Via Mobile

A clean, responsive landing page promoting a mobile shopping experience. Built with a split-screen hero layout, a simple navigation bar, and a call-to-action to drive sign-ups.

Mostrar Imagem

✨ Features
Hero section with headline, supporting text, and a "Get Started" call-to-action button
Navigation bar with Home, Work, About, and Contact links
Illustrated visual showing a mobile shopping app mockup with product categories
Split background layout (light/dark contrast between content and illustration areas)
Fully responsive design

CSS3
